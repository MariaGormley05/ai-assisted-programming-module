# Your eval suite goes here

DIY 5 asks you to build:

- `cases.json` — at least eight cases, each an input plus the properties
  its output must satisfy
- `run_evals.py` — scores the set and prints a **pass rate**

Nothing is provided beyond this note, deliberately. Writing the case file
is most of the learning: deciding what "acceptable" means for output that
is different every time is the actual skill, and a supplied answer would
remove it.
